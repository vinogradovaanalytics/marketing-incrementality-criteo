# Оценка инкрементального эффекта рекламы

Аналитический проект на данных Criteo Uplift Modeling Dataset. ДОБАВИТЬ ССЫЛКУ

Цель проекта — оценить, какая часть пользовательских конверсий действительно вызвана рекламным влиянием, а не произошла бы без рекламы, и найти группы пользователей с различным эффектом от рекламной коммуникации.

## Бизнес-задача

Обычная атрибуция показывает, какие конверсии произошли после взаимодействия пользователя с рекламой, но не отвечает на вопрос, произошли бы эти конверсии без рекламного воздействия.

В рамках проекта исследуется **инкрементальность (incrementality)** — дополнительный эффект рекламы по сравнению со сценарием, в котором рекламного воздействия не было.

Основные вопросы исследования:

- увеличивает ли рекламное воздействие вероятность визита;
- увеличивает ли оно вероятность конверсии;
- каков средний инкрементальный эффект рекламы;
- одинаков ли эффект рекламы для разных групп пользователей;
- можно ли выделить аудитории, для которых рекламное воздействие приносит наибольший дополнительный эффект.

## Данные

Используется исправленная версия **Criteo Uplift Modeling Dataset v2.1**, собранная на основе нескольких рандомизированных incrementality-тестов.

Каждая строка соответствует одному пользователю.

В датасете:

- 13 979 592 наблюдения;
- 12 обезличенных пользовательских признаков: `f0–f11`;
- `treatment` — назначение пользователя в экспериментальную группу;
- `exposure` — факт реального рекламного воздействия;
- `visit` — факт визита;
- `conversion` — факт конверсии.

Исходные признаки пользователей анонимизированы.

Сырые данные не хранятся в репозитории. Код предполагает локальное размещение датасета в `data/raw/`.
